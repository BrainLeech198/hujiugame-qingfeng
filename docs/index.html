氢风（QingFeng）是一款基于 libGDX 构建的视觉小说游戏引擎与跨平台游戏启动器。项目采用标准化的文件结构与 JSON 数据驱动的资源体系，以清晰、规范的格式组织游戏内容，为创作者提供统一而稳定的运行环境。

氢风原生支持 15 种界面语言，并提供可切换的主题系统，满足不同地区用户的个性化需求。Windows、Linux、macOS 与 Android 四大平台同步支持，覆盖桌面与移动端多种使用场景。

氢风内置完善的资源包管理体系，支持语言包、主题包、游戏语言包与游戏主题包等资源的导入与切换，帮助创作者灵活扩展游戏内容。同时附带版本检测与一键资源修复功能，确保游戏资源始终完整可用。

游戏与资源包采用专属文件格式（.qfg、.qfl、.qft、.qfgl、.qfgt），并已在 Windows、Linux、macOS、Android 多平台完成文件关联，双击即可直接加载运行。可视化编辑器、2D 地图与视频播放等扩展能力正在规划中。
