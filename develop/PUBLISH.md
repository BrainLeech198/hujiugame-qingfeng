# 版本发布记录

> **文档定位**：版本发布信息记录，面向官网玩家公告。每个已发布版本（beta 或正式版）一条记录，按发布时间倒序排列。
>
> **文档结构**：
> - 按发布时间倒序，每个版本一条记录
> - 记录标题格式：`## v<版本号>（<beta/正式版>）`
> - 每条记录含：版本类型 / 发布时间戳 / 该版本最后一次更新 commit / 面向玩家的更新摘要
>
> **更新规范**：
> 1. 【必须】每次发布新版本（beta 或正式版）→ 在本文档顶部新增一条版本发布记录
> 2. 【必须】发布时间戳 = 最后一次更新版本下载地址（`docs/data/versions.json`）的 git 提交时间
> 3. 【必须】「该版本最后一次更新」= 该版本最后一次更新版本下载地址的 git 提交短哈希（7 位，如 `8d732h8`）
> 4. 【如果】面向玩家的更新摘要 → 可作为官网 `docs/data/versions.json` 对应版本 `log` 字段的撰写素材

## v1.0.0-beta-26w33b（beta）

- **版本类型**：beta 测试版
- **发布时间**：2026-08-14 23:51（以最后一次更新版本下载地址的提交 `9500e9d` 时间为准）
- **该版本最后一次更新**：`9500e9d`
- **面向玩家的更新摘要**：
  - 修复 mac 卡死：修复 mac 版点击游戏内路径标签（打开资源管理器）、以及出现系统原生弹窗（如崩溃提示）时游戏卡死的问题
  - 修复误弹「版本不一致」无法进游戏：旧版用版本号字符串比较判断版本兼容，可能把兼容游戏误判为「版本不一致」；本次改用「版本码」判定（主版本相等 + 次版本不低于要求），判断更准确，不再误拦
  - 修复缺版本要求误判：游戏未声明启动器版本要求时，旧版可能误弹「版本不一致」；本次视为未声明直接放行
  - 新增「无法识别游戏版本要求」提示：当游戏声明了无法识别的启动器版本码时，弹窗提示并建议不要强制运行
  - mac 安装包引导改进：压缩包内安装指引更名为「安装氢风请打开Install QingFeng.command」，安装流程更清晰
  - 下载优化：测试版下载链接不再需要访问提取码，下载更省心
