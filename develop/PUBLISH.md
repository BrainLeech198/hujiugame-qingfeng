# 版本发布记录

> **文档定位**：版本发布信息记录，面向官网玩家公告。每个已发布版本（beta 或正式版）一条记录，按发布时间倒序排列。
>
> **文档结构**：
> - 按发布时间倒序，每个版本一条记录
> - 记录标题格式：`## v<版本号>（<beta/正式版>）`
> - 每条记录含：版本类型 / 发布时间戳 / 该版本最后一次更新 commit / 面向玩家的更新摘要
>
> **更新规范**：
> 1. 【必须】每次发布新版本（beta 或正式版）→ 在本文档顶部新增一条版本发布记录
> 2. 【必须】发布时间戳 = 最后一次更新版本下载地址（`docs/data/versions.json`）的 git 提交时间
> 3. 【必须】「该版本最后一次更新」= 该版本最后一次更新版本下载地址的 git 提交短哈希（7 位，如 `8d732h8`）
> 4. 【如果】面向玩家的更新摘要 → 可作为官网 `docs/data/versions.json` 对应版本 `log` 字段的撰写素材
> 5. 【必须】写「面向玩家的更新摘要」时，按「上一版本发布点 → 本版本发布点」之间的 commit 区间梳理玩家可见改动（修复的 Bug / 新增功能 / 优化），跨版本才生效的修复（打包之后完成的 bug 修复随下一版本发出）必须算入本版本摘要，不要遗漏；beta 测试版按此梳理书写即可，release 正式版属重要更新，需正式、系统地书写
